# QuickNotes

QuickNotes is a simple note-taking web app that allows users to create, organize, search, and delete notes. Notes can be grouped into Personal, Work, or Study categories, and the app stores them in the browser so they remain available after refreshing the page.

# Features

Add notes with Personal, Work, and Study categories
Validate empty notes and notes over 200 characters
Display notes with their category and creation date
Delete individual notes
Search notes instantly while typing
Save notes to localStorage
Responsive layout for smaller screens
-Old-money inspired interface with category-specific styling

# How to Run Locally

1. Clone the repository from GitHub.
2. Open the `quicknotes-app` folder in VS Code.
3. Open `index.html` using Live Server.
4. The QuickNotes application will open in your browser.
